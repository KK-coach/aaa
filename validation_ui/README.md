# Validation UI

Admin tool for scoring archived audits (AAA-67). Single-user, EN-only,
desktop-only, local Phase 1.

## Run

```
cd /path/to/repo
python -m streamlit run validation_ui/app.py
```

Opens at http://localhost:8501

Use `python -m streamlit` (not the bare `streamlit` CLI) — see AAA-66
Area 1 (local `streamlit.exe`/`-ip` pip issue).
